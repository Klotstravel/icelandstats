# Исландия статистика — stats.klotstravel.com

Публичная копия страницы «Исландия статистика» (Klots Travel). Данные — Statistics Iceland.

- `index.html` — готовый сайт (собирается автоматически, руками не править).
- `src/page.html` — код страницы (тот же, что в артефакте Claude).
- `src/data/*.csv` — данные.
- `src/build_site.py` — сборка: `python3 src/build_site.py src/page.html src/data .`

Порядок обновления описан в документе проекта «05 Инструкция — статистика Исландии».
